# CSS Typography

## About This Project

This project is part of my software and web development course. I'm using it to practise CSS typography and understand how different font choices and text styles affect the look and feel of a website.

I'll be experimenting with headings, paragraphs, font combinations and spacing to see how to make text look good while keeping it easy to read.

## What I'm Working On

- **Font families** – experimenting with different fonts and understanding the difference between serif, sans-serif and monospace.
- **Font sizes and weights** – creating a clear visual difference between headings, subheadings and body text.
- **Line height** – improving readability by adjusting the space between lines.
- **Letter and word spacing** – exploring how spacing affects the appearance of text.
- **Text alignment** – practising left, centre and right alignment.
- **Text decoration and transformation** – using properties such as `text-decoration` and `text-transform`.
- **Responsive typography** – making text work well on different screen sizes.
- **Font pairing** – combining fonts to create a consistent look across a page.

## Technologies Used

- HTML5
- CSS3

## What I've Learned

This project gives me the chance to experiment with different typography styles and understand how CSS can improve the readability and appearance of a webpage.
